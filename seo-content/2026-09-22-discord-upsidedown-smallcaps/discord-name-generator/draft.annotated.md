# Annotated draft — coverage markup (discord name generator)

Bold = tier-1/2 concept covered, with its relationship stated (not a bare mention).

Discord actually has three separate name fields: **@username** (a-z, 0-9, underscore,
period only), **display name** (full **Unicode**, **32-character limit**), and **server
nickname** (per-server override of display name, same rules). Fancy fonts and symbols work
in the display name and nickname — never the @username.

FAQ covers: username/display-name/nickname distinction, 32-char limit, **no Nitro
required**, **how to change** your display name and set a nickname, symbol-wrap template
character-count caveat, channel-name rules, readability trade-off.
